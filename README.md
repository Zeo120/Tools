# Tools

A collection of developer and diagnostic tools.

## Available Tools

- **[android-power-meter](android-power-meter/)**: Real-time power monitoring CLI for Android devices with 100ms sampling, 60 FPS display, and a Braille dial meter.
- **[speedtest](speedtest/)**: Proprietary Speed Test Suite featuring a zero-dependency 10Gbps+ server daemon, web GUI, LAN auto-discovery, direct-pipe internet testing without 3rd-party APIs, and a 60 FPS Braille speedometer dial.
